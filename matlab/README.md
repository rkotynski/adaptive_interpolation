# MATLAB / GNU Octave

**EN:** `probkuj_adaptacyjnie` implements adaptive sampling with two interpolation models and probabilistic exploration. By default, each iteration has a 75% chance to select an interval using the interpolation discrepancy and a 25% chance to bisect the longest eligible interval. `udzial_eksploracji` sets the exploration probability (`0.25` by default). `ziarno_losowe` controls the random seed and `info.historia_trybow` records the mode selected for every new point. Set `udzial_eksploracji=0` to disable exploration. Run `test_probkowania` to check the numerical behavior and `przyklad_probkowania` to generate a demonstration. GIF export requires compatible graphics support for `getframe` and `imwrite`.

**PL:** Funkcja `probkuj_adaptacyjnie` realizuje adaptacyjne próbkowanie z porównywaniem dwóch interpolantów i losową eksploracją. Domyślnie przy każdym wyborze nowego punktu z prawdopodobieństwem 75% stosowana jest rozbieżność interpolantów, a z prawdopodobieństwem 25% dzielony jest najdłuższy dopuszczalny przedział. Parametr `udzial_eksploracji` określa prawdopodobieństwo eksploracji (domyślnie `0.25`). `ziarno_losowe` ustala ziarno generatora losowego, a `info.historia_trybow` zapisuje tryb wyboru każdego nowego punktu. Ustaw `udzial_eksploracji=0`, aby wyłączyć eksplorację. Uruchom `test_probkowania` dla testów oraz `przyklad_probkowania` dla przykładu z animacją. Zapis GIF wymaga obsługi `getframe` i `imwrite` przez środowisko graficzne.
